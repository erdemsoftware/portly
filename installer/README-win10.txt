Portly - Windows 10 / 11
========================

1. Put this folder somewhere without spaces, for example C:\Portly
2. Run Portly.exe
3. On the first start choose the packages to download (the recommended set is selected) and click "Install selected"
4. Click "Start all". Every folder in the www folder becomes a site: www\shop -> https://shop.test

Portly updates itself and its package list (Menu > Check for updates).
Your packages (bin), databases (data), projects (www) and settings (usr) are never touched by updates.

Free, open source, no ads.  https://github.com/erdemsoftware/portly

Portly - Windows 10 / 11

1. Bu klasörü yolunda boşluk olmayan bir yere koyun, örneğin C:\Portly
2. Portly.exe'yi çalıştırın
3. İlk açılışta indirilecek paketleri seçin (önerilenler seçili gelir) ve "Seçilenleri kur"a tıklayın
4. "Hepsini başlat"a tıklayın. www klasöründeki her klasör bir site olur: www\magaza -> https://magaza.test

Portly kendini ve paket listesini günceller (Menü > Güncellemeleri denetle).
Paketleriniz (bin), veritabanlarınız (data), projeleriniz (www) ve ayarlarınız (usr) güncellemede değişmez.

Ücretsiz, açık kaynak, reklamsız.  Erdem Software
