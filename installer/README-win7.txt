Portly Legacy - Windows 7 SP1 / 8 / 8.1 (64-bit)
================================================

Requirements: Windows 7 SP1 64-bit with .NET Framework 4.8
(https://dotnet.microsoft.com/download/dotnet-framework/net48). Windows 8.1 already has it after Windows Update.

1. Put this folder somewhere without spaces, for example C:\Portly
2. Run Portly.exe and choose the packages on the first start
3. Click "Start all"

This edition contains package versions that still run on Windows 7 / 8 / 8.1
(PHP up to 8.2, MySQL 5.7, Apache 2.4 VS16, Node.js 13). It does NOT receive updates.
If you move to Windows 10 / 11, download the normal edition: your bin, data, www and usr folders can be copied over.

Free, open source, no ads.  https://github.com/erdemsoftware/portly

Portly Legacy - Windows 7 SP1 / 8 / 8.1 (64 bit)

Gereksinim: Windows 7 SP1 64 bit ve .NET Framework 4.8. Windows 8.1'de Windows Update ile zaten gelir.

1. Bu klasörü yolunda boşluk olmayan bir yere koyun, örneğin C:\Portly
