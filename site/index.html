Projects

Drop a folder in, open it over HTTPS

Every folder in www becomes a site with its own address, such as https://shop.localhost, signed by a local certificate authority your browser trusts.

  • No virtual host files, no editing the hosts file by hand
  • Recognises WordPress, Laravel and other projects
  • A different PHP version for each project

Packages

Any version, one click away

Install, switch and remove versions of PHP, web servers and databases without leaving the app. Old projects keep their PHP while new ones use the latest.

  • Several versions installed side by side
  • Update notices for new releases of what you use
  • PHP extensions such as Xdebug in a few clicks

Settings

Portable, and yours to adjust

Unzip Portly anywhere and run it, or use the installer. Ports, domain ending, document root, theme and language are one screen away.

  • 31 languages, light and dark theme
  • Settings can be exported and imported
  • Start with Windows and stay in the tray if you like
