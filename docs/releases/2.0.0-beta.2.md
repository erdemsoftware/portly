**Portly 2.0 beta 2: macOS, Linux and a new app for Windows 10 / 11.**

This is a pre-release. Portly 1.2.3 stays the stable version, and its in-app updater does not offer this beta.

### Fixed since beta 1

- Windows: started next to Portly 1.x, the beta emptied 1.x's block in the hosts file, so the 1.x sites (`name.test`, `name.portly` ...) stopped opening. Each Portly folder now changes only its own block. If this happened to you, restart the web server in Portly 1.x once: it writes its entries back.
- PHP and MySQL could be reported as "did not answer in time" while they were in fact running (on some PCs Windows' list of open ports shows a new port late). Portly now also checks the port with a direct connection.
- A service that stops unexpectedly while Portly sits in the tray now shows a notification.
- After an unexpected MySQL stop, Portly no longer says the data files look damaged when nothing points to that.
- Service mode (Windows): the PHP row shows its port again.

### Install

**macOS and Linux**: one line, no sudo. It downloads the file for your system, checks its SHA-256 and installs Portly (macOS: `/Applications/Portly.app`; Linux: `~/.local/share/portly` with a menu entry):

```sh
curl -fsSL https://raw.githubusercontent.com/erdemsoftware/portly/main/tools/install.sh | sh
```

Or download a file below: `.dmg` / `.zip` (macOS), `.AppImage`, `.deb` or `.tar.gz` (Linux).

**Windows 10 / 11**: `Portly-2.0.0-beta.2-windows-x64.zip`. Unzip it into a new folder (not over your 1.x folder) and start `Portly.exe`. Stop Portly 1.x first (both use ports 80, 443 and 3306). To keep working with your projects, point the beta's document root (Settings) at your 1.x `www` folder; your 1.x folder and data stay untouched.

### What is new

- One app for **Windows, macOS (Apple Silicon and Intel) and Linux (x64 and arm64)**, with the same version number everywhere.
- macOS / Linux: PHP (php-fpm, with **Xdebug**), Caddy, **Apache**, **Nginx**, MySQL 8.4, MariaDB (Linux x64), PostgreSQL, MongoDB, Redis, **Memcached**, Mailpit, Node.js, Composer, WP-CLI, phpMyAdmin and Adminer. Everything lives in `~/Portly`.
- Projects open at `https://name.localhost`: no hosts file changes, one local certificate authority trusted once.
- In-app updates on every system (app bundle, AppImage, tar.gz, .deb, Windows zip), SHA-256 checked. They start with the first stable 2.x release; during the beta, install a newer beta the same way as this one.
- All 31 languages.

### Known limits

- The macOS app is ad-hoc signed, not notarized (no paid Apple Developer account). The installer removes the quarantine flag. If you open a downloaded `.dmg`, right-click Portly.app > Open the first time.
- MySQL on macOS needs macOS 15; MongoDB needs macOS 14.
- MariaDB is offered on Linux x64 only. PostgreSQL on Linux comes from the third-party Zonky builds and has no `psql`.
- Portly's own Linux builds (Apache, Nginx, Memcached, PHP with Xdebug) need glibc 2.34+ (PHP 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer). On older systems the static PHP builds are offered instead.
- Windows 7 / 8 / 8.1: stay on Portly 1.x Legacy.

Please report problems at https://github.com/erdemsoftware/portly/issues.

**Portly 2.0 beta 2: macOS, Linux ve Windows 10 / 11 için yeni uygulama.**

Bu bir ön sürüm. Kararlı sürüm Portly 1.2.3 olarak kalıyor; 1.x'in uygulama içi güncellemesi bu betayı önermez.

**Beta 1'den bu yana düzeltilenler:**

- Windows: Portly 1.x'in yanında çalıştırılan beta, hosts dosyasındaki 1.x bölümünü boşaltıyordu; 1.x siteleri (`ad.test`, `ad.portly` ...) açılmaz oluyordu. Artık her Portly klasörü yalnız kendi bölümünü değiştiriyor. Bu sizde olduysa Portly 1.x'te web sunucusunu bir kez yeniden başlatın; kayıtlarını geri yazar.
- PHP ve MySQL aslında çalışırken "zamanında yanıt vermedi" diye gösterilebiliyordu (bazı bilgisayarlarda Windows'un açık port listesi yeni portu geç gösteriyor). Portly artık portu doğrudan bağlanarak da kontrol ediyor.
- Portly sistem tepsisindeyken beklenmedik şekilde duran bir servis artık bildirim gösteriyor.
- MySQL beklenmedik şekilde durduğunda, buna işaret eden bir şey yokken "veri dosyaları bozulmuş görünüyor" denmiyor.
- Servis modu (Windows): PHP satırı yine portunu gösteriyor.

- **macOS ve Linux:** `curl -fsSL https://raw.githubusercontent.com/erdemsoftware/portly/main/tools/install.sh | sh` (sudo gerekmez, SHA-256 denetlenir) ya da aşağıdaki `.dmg` / `.zip`, `.AppImage`, `.deb`, `.tar.gz` dosyaları.
- **Windows 10 / 11:** `Portly-2.0.0-beta.2-windows-x64.zip` dosyasını yeni bir klasöre açın (1.x klasörünün üstüne değil) ve `Portly.exe`'yi çalıştırın.
- Yenilikler: Windows, macOS ve Linux'ta tek uygulama; macOS / Linux'ta Xdebug'lı PHP, Caddy, Apache, Nginx, MySQL, MariaDB, PostgreSQL, MongoDB, Redis, Memcached, Mailpit, Node.js; projeler `https://ad.localhost` adresinde; her sistemde kendini güncelleme; 31 dil.
- Sınırlar: macOS uygulaması ücretli Apple hesabı olmadan imzalandığı için ilk açılışta sağ tık > Aç gerekebilir (kurulum betiği bunu kendisi halleder); macOS'ta MySQL için macOS 15, MongoDB için 14 gerekir; MariaDB yalnız Linux x64'te; Windows 7 / 8 / 8.1 kullanıcıları 1.x Legacy'de kalır.

Sorunları https://github.com/erdemsoftware/portly/issues adresine bildirin.
